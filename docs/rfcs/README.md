# RFCs

RFCs are for proposed changes that need team discussion before implementation.

Use ADRs for final decisions. Use RFCs for ideas that are still being shaped.

Good RFC candidates for CivicFix:

- choosing Azure Container Registry instead of GitHub Container Registry
- enabling real Azure deployment
- adding managed PostgreSQL migration strategy
- adding authentication and user roles
- adding Alertmanager notification routing
- adding production DNS and TLS automation

## RFC workflow

1. Create a new RFC from the template.
2. Describe the problem, proposal, alternatives, and risks.
3. Discuss with the team.
4. If accepted, implement the change.
5. Create or update an ADR if the proposal becomes a long-term decision.
